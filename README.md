# DARAK Digital Presence

A brand-led website concept for luxury interior design and finishing services, combining visual presentation with lead-generation structure.

## Overview

A premium digital presence for an interior design and finishing brand, built with React, TypeScript, and Vite.

## Highlights

- Premium brand presentation
- Responsive service sections
- Lead-generation focused CTAs
- Deployment configuration for modern hosting

## Tech stack

React, TypeScript, Vite, Tailwind CSS, ESLint

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown by the development server. For a production build:

```bash
npm run build
npm run preview
```

## Available scripts

| Script | Command |
|---|---|
| `dev` | `vite` |
| `build` | `vite build` |
| `lint` | `eslint .` |
| `preview` | `vite preview` |

## Project structure

The application code lives in `src/`, static assets are served from `public/`, and the project configuration is kept at the repository root.

## Environment variables

Do not commit credentials or production secrets. Copy the example environment file when one is provided and keep local secrets in `.env.local`.
